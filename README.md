# Пости конкурентів: які з них спрацювали

Локальний застосунок. Одна кнопка збирає всі пости конкурентів за останні 80 днів у LinkedIn, Instagram і YouTube. Потім модель Jev оцінює кожен пост на сім питань, а застосунок показує ті, що вистрілили в автора й підходять вашій аудиторії. З цього беруться теми для власних постів, хуки й формати.

Усе працює на вашому комп'ютері. Назовні йдуть лише запити до сервісів збору даних і до моделі. Ключі лежать у файлі `.env`, який не потрапляє в git.

## Requirements & integrations

| Сервіс | Навіщо | Обов'язково? | Де взяти |
|---|---|---|---|
| Python 3.10+ і `httpx` | запуск застосунку | так | `python3 --version`, далі `pip3 install -r requirements.txt` |
| HarvestAPI | пости LinkedIn (сторінки компаній і особисті профілі) | так | harvestapi.io → API key → `HARVESTAPI_KEY` у `.env`. Сторінка з 50 постів коштує близько $0,004 |
| OpenRouter | модель Jev, яка оцінює кожен пост | так | openrouter.ai → Keys → `OPENROUTER_API_KEY` у `.env`. Поповніть на $5, один прогін бере $0,02–0,10 |
| Apify | пости Instagram | ні | apify.com → Settings → API → `APIFY_API_TOKEN`. Без токена Instagram пропускається |
| YouTube Data API або `yt-dlp` | відео YouTube | ні | ключ Google Cloud у `YOUTUBE_DATA_API_KEY` або `brew install yt-dlp` |
| Claude Code | підкручує питання Jev на пробній вибірці перед повним прогоном | ні | `claude --version`. Без нього прогін іде з базовими питаннями |
| `ffmpeg`, `yt-dlp`, `openai-whisper` | розшифровка й покадровий розбір збережених постів | ні | для самого прогону не потрібні |

## Перший запуск

```bash
git clone https://github.com/victor-shulga/competitor-post-scout.git
cd competitor-post-scout
pip3 install -r requirements.txt
cp .env.example .env        # впишіть HARVESTAPI_KEY і OPENROUTER_API_KEY
cp brain.example.json brain.json   # впишіть себе і конкурентів
python3 server.py --open
```

Відкриється http://127.0.0.1:4317. Угорі видно стан ключів: зелений чип означає «готово», сірий означає, що мережу буде пропущено (наведіть мишку, там написано чому).

Оберіть мережі й натисніть кнопку запуску. LinkedIn по 30 акаунтах займає 5–10 хвилин. Журнал прогону видно на сторінці в реальному часі.

## Налаштування під вашу агенцію

| Файл | Що в ньому |
|---|---|
| `brain.json` | хто ви, ваш ICP, теми і список конкурентів з посиланнями на LinkedIn, Instagram, YouTube. Створюється з `brain.example.json`. Першими йдуть ваші власні акаунти з позначкою `(ви)` в кінці назви: так видно, де ви стоїте серед конкурентів |
| `jev/competitor-hunt.json` | сім питань, на які Jev відповідає про кожен пост: тема, наскільки пост корисний вашому покупцю, тип хука, доказ, чи можна повторити, чи це реклама, чи прив'язаний до новини |
| `web/brand.css` | порожній шар для ваших кольорів і шрифтів, якщо хочете свій бренд |

Теми постів за замовчуванням підходять будь-якій B2B-агенції: метод і інструкція, кейси й результати, думка про ринок, послуги й запрошення, історія засновника, поза нішею. Їх можна перейменувати в `jev/competitor-hunt.json` під свою нішу. Тему `off_niche` залишайте: за нею застосунок відсіює пости поза нішею.

Конкурента можна додати просто зі сторінки: вставте посилання на профіль. Він збережеться в `roster.json` поруч із `brain.json`. Щоб додати назавжди, допишіть рядок у `brain.json` → `competitors`:

```json
{ "name": "Назва компанії", "platform": "LinkedIn", "handle": "https://www.linkedin.com/company/slug/" }
```

`platform` буває `LinkedIn`, `Instagram` або `YouTube`. Для LinkedIn підходять і сторінки компаній (`/company/...`), і особисті профілі (`/in/...`). Беріть 10–20 конкурентів вашого розміру і їхніх засновників: у сервісних компаніях засновник часто пише більше за сторінку компанії.

## Як читати результат

- **Мапа.** Кожна точка = пост. Праворуч ті, що відірвались від звичайного рівня свого автора. Вище ті, що зібрали більше охоплення.
- **Найкращі пости.** Відсортовані за балом: відрив від медіани автора × відповідність аудиторії × можна повторити. Реклама й пости поза нішею відсіяні.
- **Зрізи.** Які хуки, теми, формати й автори частіше дають хіти (хіт = пост, що зібрав щонайменше вдвічі більше за медіану свого автора).
- **Охоплення в LinkedIn** = реакції + коментарі. Покази LinkedIn бачить лише сам автор, тому їх тут немає.

Пост можна зберегти в бібліотеку, розшифрувати, спитати про нього AI. У «Моїй студії» (`/studio`) підключається ваш власний YouTube.

## Запуск без сторінки

```bash
python3 engine/hunt.py all --run runs/2026-10-20 --platforms linkedin,instagram
```

Етапи: `scrape` (збір) → `pilot` (Jev на 40 постах, перевірка якості питань) → `judge` (усі пости) → `rank` (бал і мапа) → `runs/<id>/result.json`. Кожен етап можна перезапустити окремо з `--resume`.

## Якщо щось не так

| Що бачите | Причина |
|---|---|
| `HarvestAPI 401` | ключ неправильний або не вписаний у `.env` |
| `HarvestAPI 402` | закінчились кредити, поповніть на harvestapi.io |
| у компанії 0 постів | сторінка нічого не публікувала за 80 днів, або HarvestAPI не віддає її пости. Перевірте сторінку руками й напишіть у висновках «не вдалося зібрати», а не «мовчить» |
| мапа порожня одразу після запуску сервера | сторінка відкрилась раніше, ніж сервер підняв результат. Оновіть сторінку |
| чип Jev сірий | немає `OPENROUTER_API_KEY` або на рахунку менше $0,15 |
